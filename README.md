# 🌟 CIEDH — Landing Page: Cuidados com o Idoso

Landing page de alta conversão para o evento online **"3 Aulas Gratuitas — Cuidados com o Idoso"** do **CIEDH (Centro Integrado de Educação e Desenvolvimento Humano)**.

Desenvolvida com as mais modernas tecnologias web para máxima performance, SEO e compatibilidade total com **Vercel** e **GitHub**.

---

## 🚀 Tecnologias Utilizadas

- **Next.js 14** (App Router com renderização estática ultra veloz)
- **React 18** (Componentização modular e reativa)
- **Tailwind CSS** (Design system customizado com a paleta oficial CIEDH)
- **TypeScript** (Tipagem estática, segurança e manutenibilidade)
- **Lucide React** (Ícones modernos e leves)
- **Google Fonts** (`Montserrat` e `Open Sans` via `next/font/google` sem layout shift)

## 💻 Como Rodar o Projeto Localmente

1. **Instalar dependências (caso necessário):**
   ```bash
   npm install
   ```

2. **Iniciar servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```
   Acesse [http://localhost:3000](http://localhost:3000) no seu navegador.

3. **Gerar build de produção:**
   ```bash
   npm run build
   ```

---

## 🐙 Como Subir para o GitHub

No terminal, dentro da pasta do projeto (`c:\Users\Administrador\Desktop\website`):

1. **Iniciar o repositório Git:**
   ```bash
   git init
   ```

2. **Adicionar todos os arquivos:**
   ```bash
   git add .
   ```

3. **Criar o primeiro commit:**
   ```bash
   git commit -m "feat: landing page CIEDH Next.js, React e Tailwind CSS"
   ```

4. **Vincular ao seu repositório do GitHub:**
   *(Crie um novo repositório vazio no GitHub e copie o link dele)*
   ```bash
   git branch -M main
   git remote add origin https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
   git push -u origin main
   ```

---

## ⚡ Como Hospedar na Vercel (1 Clique)

1. Acesse **[vercel.com](https://vercel.com)** e faça login com sua conta do GitHub.
2. Clique em **"Add New..."** → **"Project"**.
3. Selecione o repositório que você acabou de subir no GitHub.
4. O Vercel detectará automaticamente as configurações de **Next.js**. Não precisa alterar nada no build.
5. Clique em **"Deploy"**!
6. Em menos de 1 minuto, seu site estará no ar com link HTTPS e CDN global! 🚀
